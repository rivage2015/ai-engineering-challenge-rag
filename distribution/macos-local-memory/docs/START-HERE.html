PRIVATE LOCAL MEMORY

クリックだけで、
Macの記憶を探せるように。

Local Memory Searchは、曖昧な記憶からMac内の資料を探し、根拠付きで答えるローカルシステムです。通常のAI処理でファイルを外部へ送信しません。

Local visual Reader / OCR scheduling v0.6
Answer promotion v0.5を含む（app 0.6 / build 6・未署名試作版）

始め方

  1. Local Memory Search.appを、隣のApplicationsへドラッグします。
  2. 初回だけControlクリックし、「開く」を選びます。
  3. 画面に従って「許可」を押します。PythonとOllamaがなければ公式版を自動取得します。
  4. 探したいフォルダを選びます。
  5. ブラウザで「初回セットアップ」を押します。

初回は約9GBのAIモデルを取得するため、回線によって時間がかかります。モデル取得後に画像を自動で再読します。途中でMacを再起動しても、次回起動時に安全な再実行画面へ戻ります。

必要条件

macOS 14以降。Apple Silicon、メモリ24GB以上、空き40GB以上を推奨します。

設定と索引は ~/Library/Application Support/LocalMemorySearch へ保存されます。原本は変更しません。

Word・Excel・PowerPoint

DOCXの本文・見出し・表、XLSXのシート・セル・数式、PPTXのスライド・表・対応図表・明示SmartArtを構造付きで読みます。追加のPythonライブラリがないMacでも標準ライブラリReaderを使います。

高度な書式、変更履歴、レイアウト継承、グループ座標などが解決できないときは、完全に読めたと表示せず理由を残します。アプリ更新後にReaderの再構築が必要な場合も、旧索引を維持したまま画面で案内します。

PDFと埋め込み画像

スキャンPDFや画像だけのPDFは、ページごとにMac内で画像化し、ローカルOCRの対象にします。PDF内の画像はページ上に見える状態で、OfficeとJupyter Notebookの対応画像は画像単位で読み取ります。Office・Notebookは表示時の切り抜き、透過、変形をまだ完全再現できないため、埋め込み画像のOCRも [暫定読取] として扱います。

図・表・写真をGemmaが読む場合も、見える対象、明示ラベル、矢印や凡例で明示された関係、文字で明記されたラベル付きの値だけを質問と無関係に観測します。棒の高さや軸目盛から数値を推定しません。

Gemmaの意味観測は必ず [暫定読取] です。検索用だけに使い、それ単独で確定回答を作らず、確定グラフの根拠にもしません。

  • 画像単位の対応形式はPNG、JPEG、TIFF、BMPです。
  • 手書き、低解像度、小さな文字、回転・反射、複雑な表のセル対応、ラベルのないグラフ数値は精度保証の対象外です。
  • 暗号化・破損PDFや、SVG、GIF、WebP、EMF、WMFなどの非対応画像は読めたと扱いません。

これらの描画、OCR、Gemmaの観測は完全ローカルで行い、読取対象のファイルや画像を外部へ送信しません。初回のアプリ導入とモデル取得だけは外部通信を使います。

回答の安全性

検索前に危険な命令文を分離し、機械検証と回答文脈から分けたAI監査を行います。根拠が足りないときは、推測せず「わかりません」と停止します。
