# 順序付きセクション検索の改善計画

状態: **実装・回帰試験・実索引試験・配布build 8への反映まで完了（2026-09-10）**

## 目的

「受付で一番最初にすべきお声がけ」のように、資料内の場所、項目順、発話内容の関係を求める質問を、Embeddingの近さだけではなくQuestion Evidence Graphで解決する。

## 実装ループ

1. 質問から「最初」「声がけ・挨拶」「明示されたセクション」を検出する。
2. 同じsheetで、一意の`1.`発話見出しと直後のスクリプト列セルを選ぶ。
3. `question -> section -> ordered_step -> value`を意味付きEdgeで結び、保存済みGraphのNode hashとRelation IDに固定する。
4. 検証済みEvidenceをEmbedding候補より先に回答監査へ渡す。
5. 主張値と値Evidenceの一致を回答後にも機械検査する。
6. 複数資料や複数値が競合する場合は`hold`とし、Human in the Loopへ渡す。
7. 資格情報のような回答不要セルを値候補と通常検索から除外する。

## 受け入れ条件

- 実索引で`ordered_section_lookup / ready / validation pass / used=true`となる。
- 回答が「わかりません」ではなく、「受付スク」の`1.ご挨拶 -> C6`を根拠として返る。
- 不正な別値、Evidenceの差し替え、複数資料の勝手な選択は検査で拒否する。
- 画面の回答経路に「質問グラフ（構造検索）」と表示する。

## ロールバック

今回追加した`ordered_section_lookup`生成関数、回答経路の追加分岐、主張検査、専用テストを削除すれば元の従来検索へ戻る。既存の索引・原本・判断記録は変更しない。
