## Residual witnesses are counted separately

The three `test_residual_*` methods intentionally show the declared metadata-only limits, not repaired attacks:

1. Coherent raw-text replacement with correct metadata and resealed content/Evidence/Relation identities can yield a metadata report PASS; its scope still says raw_text_binding not_verified.
2. Remove one of six records plus its containment relation, leaving five valid checked records: metadata report can PASS with counts five, while complete_membership stays not_verified. Removing every record instead is the distinct required UNVERIFIED zero-checked case.
3. Coherently change one Evidence count and let Search copy it: both Search-only validators can accept the internally matching context; an independent intermediate original check must reject it. This is not original attestation by Search.

These three must not be summed into 33 defended cases or proof that body/membership/freshness is closed. F11b and body/membership are mandatory open follow-ons.
